# epita-git-assignment-work
This repository implements three main features that extend the program's main function. Each feature was implemented by a different contributor:

feature-add — implemented by Victor
feature-subtract — implemented by Helen
feature-multiply and feature-divide — implemented by Reeaa (modifications made to the main function)

Features
Add (feature-add)
Author: Helen
Description: Adds two numbers and returns the sum. Integrated as a feature callable from the main function.

Subtract (feature-subtract)
Author: Victor 
Description: Subtracts the second number from the first and returns the result. Available through the main function.

Multiply and Divide (feature-multiply, feature-divide)
Author: Reeaa
Description: Multiplication 
These were added as modifications to the main function to support additional arithmetic modes.
